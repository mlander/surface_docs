# How this site works

This site is the argument and the map. The [Surface API proof of concept](https://www.drupal.org/project/surface) and its documentation are the reference. Pages here link into that documentation instead of copying it.

## Code is real

Every piece of code on this site is pulled at build time from the proof of concept, pinned to one commit. Nothing is pasted, so no example can drift from the code it describes. If a file moves, the build fails until the page is fixed.

## Counts say how they were counted

A count of places a value is described, or of files and lines a change adds, says how it was counted and against which version of Drupal core.

## How to help

- Pick a talking point on the [board](../board.md). Its page lists what is open and what would help.
- To question something already decided, read its decision record first, then follow [Proposing a change](../open/proposing-a-change.md).
- To fix the site's own text, use the edit link at the top of any page, or open an issue in the [site's repository](https://github.com/mlander/surface_docs).

Questions about the proof of concept itself go to its [issue queue](https://www.drupal.org/project/issues/surface).
