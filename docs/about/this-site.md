# How this site works

This site makes the case for moving the [Surface API proof of concept](https://www.drupal.org/project/surface) into core. The proof of concept's own documentation is the reference, and pages here link to it instead of copying it.

Every code snippet is pulled at build time from the proof of concept, pinned to one commit, so no example can drift from the code it shows. If a file moves, the build fails until the page is fixed.

Questions about the proof of concept go to its [issue queue](https://www.drupal.org/project/issues/surface). To revisit a decision, see [Proposing a change](../open/proposing-a-change.md). Fixes to this site's text go to the [site's repository](https://github.com/mlander/surface_docs), or use the edit link at the top of any page.
